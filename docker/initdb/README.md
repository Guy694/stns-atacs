วางไฟล์ dump ของฐานข้อมูล (เช่น `01-stn_atacs.sql`) ไว้ในโฟลเดอร์นี้ **ก่อนสั่ง `docker compose up` ครั้งแรก**
MariaDB จะโหลดไฟล์ `.sql` / `.sql.gz` ที่นี่อัตโนมัติเฉพาะตอนที่ volume ฐานข้อมูลยังว่าง
ถ้าฐานข้อมูลเริ่มทำงานไปแล้ว ให้นำเข้าด้วยคำสั่งใน docs/deploy-docker.md แทน
ไฟล์ dump มีข้อมูลจริง อย่า commit เข้า git
