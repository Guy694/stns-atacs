# คู่มือนำเข้าครุภัณฑ์ด้วย CSV

เอกสารนี้อธิบายการเพิ่มและแก้ไขข้อมูลครุภัณฑ์คอมพิวเตอร์ใน ATACS ด้วยไฟล์ CSV โดยผู้ใช้ควรดาวน์โหลดไฟล์ตัวอย่างจากปุ่ม **นำเข้า CSV** ก่อนทุกครั้ง เพื่อให้ชื่อคอลัมน์และรูปแบบข้อมูลตรงกับระบบ

## ขั้นตอนการนำเข้า

1. ไปที่หน้า **รายการครุภัณฑ์และทรัพย์สิน** แล้วกด **นำเข้า CSV**
2. เลือกหน่วยบริการที่เป็นเจ้าของข้อมูลในไฟล์
3. ดาวน์โหลดไฟล์ตัวอย่าง กรอกข้อมูล และบันทึกเป็น CSV แบบ UTF-8
4. อัปโหลดไฟล์ จากนั้นตรวจสอบจำนวนรายการที่เพิ่มใหม่ แก้ไข หรือข้าม

## การใช้ `id`

| กรณี | ค่า `id` ที่ต้องใส่ | ผลลัพธ์ |
|---|---|---|
| เพิ่มครุภัณฑ์ใหม่ | เว้นว่าง | ระบบเพิ่มรายการและกำหนด id ให้โดยอัตโนมัติ |
| แก้ไขครุภัณฑ์เดิม | ใส่ id จากไฟล์ Export CSV ของระบบ | ระบบแก้ไขรายการเดิมที่มี id ตรงกัน |
| ไม่พบ id | ใส่ตัวเลขที่ไม่มีในระบบ | ระบบข้ามแถวและแจ้งข้อผิดพลาด |
| id อยู่คนละหน่วยบริการ | ใส่ id ที่ไม่ตรงกับหน่วยบริการที่เลือก | ระบบข้ามแถวเพื่อป้องกันการแก้ไขข้อมูลข้ามหน่วยบริการ |

> ห้ามสร้างหรือคาดเดาค่า `id` เอง หากต้องการแก้ไขข้อมูลเดิม ให้ Export CSV จากระบบล่าสุด แล้วคงค่า `id` ของแต่ละแถวไว้

## วิธีดู `work_group_id` ของหน่วยบริการ

หลังเลือกหน่วยบริการในหน้าต่าง **นำเข้า CSV** ระบบจะแสดงตาราง **Work Group ของหน่วยบริการ** ทันที โดยตารางจะมีชื่อกลุ่มงานและตัวเลข `work_group_id` ที่ถูกต้องสำหรับหน่วยบริการนั้น ให้คัดลอกตัวเลขดังกล่าวใส่ในคอลัมน์ `work_group_id` ของแต่ละแถวที่เกี่ยวข้อง

> `work_group_id` ไม่ใช่เลขลำดับในไฟล์ และไม่สามารถใช้ข้ามหน่วยบริการได้ หากหน่วยบริการที่เลือกไม่มีกลุ่มงานที่เปิดใช้งาน ระบบจะแจ้งให้เว้นคอลัมน์นี้ว่างได้

## คอลัมน์สำคัญ

| คอลัมน์ | ใช้สำหรับ | ข้อกำหนด |
|---|---|---|
| `id` | ระบุการแก้ไขข้อมูลเดิม | เว้นว่างเพื่อเพิ่มใหม่; ใช้ id ที่ Export มาเพื่อแก้ไข |
| `work_group_id` | ระบุกลุ่มงานของหน่วยบริการ | ต้องระบุเมื่อหน่วยบริการมีการกำหนดกลุ่มงาน |
| `asset_name` | ชื่อครุภัณฑ์ | จำเป็นทุกแถว |
| `asset_class` | กลุ่มครุภัณฑ์ | `IT`, `Office`, `Medical`, `Vehicle`, `Building`, `Utility` หรือ `Other` |
| `asset_category` | ลักษณะทรัพย์สิน | `Hardware` หรือ `Software` |
| `windows_license_status` | สถานะ Windows | คอมพิวเตอร์ต้องใช้ `Genuine` หรือ `Pirated` |
| `purchase_date`, `maintenance_start_date`, `maintenance_end_date`, `installed_at` | วันที่ | ใช้รูปแบบ `YYYY-MM-DD` |
| `public_ip` | IP สาธารณะ | ใช้รูปแบบ IPv4 ที่ถูกต้อง |

ระบบตรวจสอบเลขทะเบียนและ Serial Number ที่ซ้ำภายในหน่วยบริการ รวมถึงตรวจสอบว่าราคาซื้อไม่ติดลบ วันที่ซื้อไม่เกินวันปัจจุบัน และวันสิ้นสุดสัญญา MA ไม่อยู่ก่อนวันเริ่มสัญญา

## ข้อแนะนำก่อนอัปโหลด

ควรทดลองนำเข้าจำนวนน้อยก่อนทุกครั้ง และตรวจสอบผลลัพธ์หลังนำเข้า หากโปรแกรมตารางคำนวณแสดงภาษาไทยผิดปกติ ให้เลือกการเข้ารหัส UTF-8 ขณะเปิดหรือบันทึกไฟล์ CSV
