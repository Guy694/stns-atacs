# คู่มือนำเข้าครุภัณฑ์ด้วย CSV

เอกสารนี้อธิบายการเพิ่มและแก้ไขข้อมูลทรัพย์สินและครุภัณฑ์ทุกกลุ่มใน ATACS ด้วยไฟล์ CSV โดยผู้ใช้ควรดาวน์โหลดไฟล์ตัวอย่างจากปุ่ม **นำเข้า CSV** ก่อนทุกครั้ง เพื่อให้ชื่อคอลัมน์และรูปแบบข้อมูลตรงกับระบบ

## ขั้นตอนการนำเข้า

1. ไปที่หน้า **รายการครุภัณฑ์และทรัพย์สิน** แล้วกด **นำเข้า CSV**
2. เลือกหน่วยบริการที่เป็นเจ้าของข้อมูลในไฟล์
3. ดาวน์โหลดไฟล์ตัวอย่าง กรอกข้อมูล และบันทึกเป็น CSV แบบ UTF-8
4. อัปโหลดไฟล์ จากนั้นตรวจสอบจำนวนรายการที่เพิ่มใหม่ แก้ไข หรือข้าม

## การใช้ `id`

| กรณี | ค่า `id` ที่ต้องใส่ | ผลลัพธ์ |
|---|---|---|
| เพิ่มครุภัณฑ์ใหม่ | เว้นว่าง | ระบบเพิ่มรายการและกำหนด id ให้โดยอัตโนมัติ |
| แก้ไขครุภัณฑ์เดิม | ใส่ id จากไฟล์ Export CSV ของระบบ | ระบบแก้ไขรายการเดิมที่มี id ตรงกัน |
| ไม่พบ id | ใส่ตัวเลขที่ไม่มีในระบบ | ระบบข้ามแถวและแจ้งข้อผิดพลาด |
| id อยู่คนละหน่วยบริการ | ใส่ id ที่ไม่ตรงกับหน่วยบริการที่เลือก | ระบบข้ามแถวเพื่อป้องกันการแก้ไขข้อมูลข้ามหน่วยบริการ |

> ห้ามสร้างหรือคาดเดาค่า `id` เอง หากต้องการแก้ไขข้อมูลเดิม ให้ Export CSV จากระบบล่าสุด แล้วคงค่า `id` ของแต่ละแถวไว้

## วิธีดู `work_group_id` ของหน่วยบริการ

หลังเลือกหน่วยบริการในหน้าต่าง **นำเข้า CSV** ระบบจะแสดงตาราง **Work Group ของหน่วยบริการ** ทันที โดยตารางจะมีชื่อกลุ่มงานและตัวเลข `work_group_id` ที่ถูกต้องสำหรับหน่วยบริการนั้น ให้คัดลอกตัวเลขดังกล่าวใส่ในคอลัมน์ `work_group_id` ของแต่ละแถวที่เกี่ยวข้อง

> `work_group_id` ไม่ใช่เลขลำดับในไฟล์ และไม่สามารถใช้ข้ามหน่วยบริการได้ หากหน่วยบริการที่เลือกไม่มีกลุ่มงานที่เปิดใช้งาน ระบบจะแจ้งให้เว้นคอลัมน์นี้ว่างได้

## คอลัมน์สำคัญ

| คอลัมน์ | ใช้สำหรับ | ข้อกำหนด |
|---|---|---|
| `id` | ระบุการแก้ไขข้อมูลเดิม | เว้นว่างเพื่อเพิ่มใหม่; ใช้ id ที่ Export มาเพื่อแก้ไข |
| `work_group_id` | ระบุกลุ่มงานของหน่วยบริการ | ต้องระบุเมื่อหน่วยบริการมีการกำหนดกลุ่มงาน |
| `asset_name` | ชื่อครุภัณฑ์ | จำเป็นทุกแถว |
| `asset_class` | กลุ่มครุภัณฑ์ | `IT`, `Office`, `Medical`, `Vehicle`, `Building`, `Utility` หรือ `Other` |
| `asset_category` | ลักษณะทรัพย์สิน | `Hardware` หรือ `Software` |
| `windows_license_status` | สถานะ Windows | คอมพิวเตอร์ต้องใช้ `Genuine` หรือ `Pirated` |
| `purchase_date`, `maintenance_start_date`, `maintenance_end_date`, `installed_at` | วันที่ | ใช้รูปแบบ `YYYY-MM-DD` |
| `public_ip` | IP สาธารณะ | ใช้รูปแบบ IPv4 ที่ถูกต้อง |

ระบบตรวจสอบเลขทะเบียนและ Serial Number ที่ซ้ำภายในหน่วยบริการ รวมถึงตรวจสอบว่าราคาซื้อไม่ติดลบ วันที่ซื้อไม่เกินวันปัจจุบัน และวันสิ้นสุดสัญญา MA ไม่อยู่ก่อนวันเริ่มสัญญา

## ข้อแนะนำก่อนอัปโหลด

ควรทดลองนำเข้าจำนวนน้อยก่อนทุกครั้ง และตรวจสอบผลลัพธ์หลังนำเข้า หากโปรแกรมตารางคำนวณแสดงภาษาไทยผิดปกติ ให้เลือกการเข้ารหัส UTF-8 ขณะเปิดหรือบันทึกไฟล์ CSV

## การนำเข้าสำหรับเจ้าหน้าที่ทั่วไป

เจ้าหน้าที่ (`officer`) เปิดหน้ารายการทรัพย์สินของหน่วยบริการที่รับผิดชอบ แล้วกด **นำเข้า CSV** ได้โดยไม่ต้องเป็นแอดมิน ระบบเลือกหน่วยบริการของหน้านั้นให้อัตโนมัติ รองรับ CSV, XLSX และ XLS

ดาวน์โหลดไฟล์ตัวอย่างจากหน้าต่างนำเข้า เว้น `id` ว่างเพื่อเพิ่มรายการใหม่ หรือใช้ `id` ของรายการเดิมในหน่วยบริการเดียวกันเพื่อแก้ไข และกรอก `work_group_id` ตามรายการที่แสดง หากหน่วยบริการมีกลุ่มงาน

การเพิ่มและแก้ไขขึ้นกับสิทธิ์ของบัญชี บัญชีดูอย่างเดียว (`viewer`) ไม่สามารถนำเข้าได้ เมื่อนำเข้าเสร็จ ให้ตรวจจำนวนรายการที่เพิ่ม แก้ไข และข้าม พร้อมข้อความผิดพลาดรายแถวก่อนปิดหน้าต่าง

## กลุ่มทรัพย์สินและการรักษาข้อมูลเดิม

- เพิ่มรายการด้วยไฟล์เดิมที่ไม่มี asset_class: ใช้ IT; แก้ไขรายการเดิมโดยเว้น asset_class ว่าง: รักษากลุ่มเดิม
- ช่องว่างหรือคอลัมน์ที่ไม่ส่งในการแก้ไข CSV จะไม่ล้างวันที่ สถานะ เลขทะเบียน และข้อมูลอื่นที่มีอยู่ หากต้องการล้างค่า ให้ใช้ฟอร์มแก้ไขของระบบ
- asset_category, device_type, OS, IP และ Windows License ใช้กับ IT; สำหรับ Office, Medical, Vehicle, Building, Utility และ Other ให้เว้นข้อมูล IT ว่าง ระบบเก็บ Hardware เพื่อรองรับโครงสร้างเดิม แต่ไม่นับเป็น IT Hardware
- คอมพิวเตอร์ IT Hardware ต้องมี windows_license_status; การแก้ไขที่ไม่ส่งค่านี้จะใช้ตรวจสอบกับค่าที่มีอยู่
- การระบุ asset_class ใหม่ใน CSV ถือเป็นการเปลี่ยนกลุ่มอย่างชัดเจน ระบบบันทึกประวัติ; รายการที่ผูก Agent อยู่เปลี่ยนเป็น non-IT ไม่ได้จนกว่าจะยกเลิกการเชื่อม
- ระยะนี้รองรับข้อมูลกลาง เช่น ยี่ห้อ รุ่น รายละเอียด Serial Number การจัดซื้อ และสัญญา ฟิลด์เฉพาะประเภทและประเภทย่อยจะเปิดใช้งานในระยะถัดไป

ตัวอย่างข้อมูลกลาง (เลือกหน่วยบริการและระบุ work_group_id ตามข้อกำหนดของหน่วยงาน):

```csv
asset_name,asset_class,manufacturer_brand,manufacturer_model,manufacturer_specification,current_status
โต๊ะทำงาน,Office,,,โต๊ะไม้ขนาด 120 x 60 ซม.,Active
เครื่องตรวจคลื่นไฟฟ้าหัวใจ,Medical,Example,ECG-1,เครื่องตรวจประจำห้องตรวจ,Active
รถยนต์ส่วนกลาง,Vehicle,Example,Car-1,รถใช้ปฏิบัติงานของหน่วยบริการ,Active
```
