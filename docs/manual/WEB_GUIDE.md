# ภาพประกอบคู่มือ ATACS

คู่มือออนไลน์อยู่ที่ `/manuals` หลังเข้าสู่ระบบ เปิดได้จากเมนู **คู่มือการใช้งาน** ใน sidebar

- เนื้อหา 12 หัวข้ออยู่ใน `lib/user-manual.ts`
- หน้าคู่มืออยู่ใน `app/(main)/manuals/`
- ภาพใน `public/manuals/images/` เป็นภาพอธิบายขั้นตอน ไม่ใช่ภาพหน้าจอข้อมูลจริง
- ภาพเดิม 4 ภาพมาจาก `docs/manual/images/` ส่วนอีก 8 ภาพสร้างจากสคริปต์

เมื่อแก้ไขภาพต้นฉบับหรือข้อความในสคริปต์ ให้สร้างภาพใหม่ด้วย:

```sh
node scripts/generate-manual-images.mjs
```

ลิงก์แต่ละหัวข้อใช้ hash เช่น `/manuals#csv-import` เพื่อเปิดหรือแชร์หัวข้อโดยตรง เมนูคู่มือใช้การตั้งค่าการแสดงเมนูเดิม และไม่ต้องกำหนดสิทธิ์เพิ่มเติมสำหรับแต่ละบทบาท
