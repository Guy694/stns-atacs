# ประเภททรัพย์สินตามตารางอายุการใช้งาน

ทะเบียนใช้ประเภทหลัก 20 ประเภทจาก `ตารางกำหนดอายุการใช้งานและอัตราค่าเสื่อ.pdf` โดยลำดับและรหัสอยู่ใน `lib/asset-classes.ts` และเกณฑ์อายุ/ค่าเสื่อมอยู่ใน `lib/asset-depreciation.ts`

- เพิ่มรายการใหม่ผ่านทะเบียนส่วนกลางหรือหน้าหน่วยงาน เลือกประเภทหลักและประเภทย่อย แล้วกรอกข้อมูลทั่วไปและรายละเอียดเฉพาะประเภท
- รหัส IT ใช้กับครุภัณฑ์คอมพิวเตอร์ ส่วนรายการใหม่ประเภทสินทรัพย์ไม่มีตัวตนใช้ Intangible
- ซอฟต์แวร์ IT เดิมยังแก้ไขได้ และรวมอยู่ในตัวกรองสินทรัพย์ไม่มีตัวตน ไม่เปลี่ยนรหัสข้อมูลเดิมอัตโนมัติ
- Building และ Utility เป็นกลุ่มเดิม เก็บไว้สำหรับการค้นหาและแก้ไขรายการเดิม การจำแนกใหม่ใช้ PermanentBuilding, Structure หรือ Electrical ตามทรัพย์สินจริง การเปลี่ยนประเภทต้องยืนยันผ่านฟอร์มเดิม
- อายุและอัตราค่าเสื่อมเป็นเกณฑ์อ้างอิง ไม่ใช่การคำนวณมูลค่าทางบัญชี

## เตรียมฐานข้อมูลในสภาพแวดล้อมอื่น

ต้องมี `add_asset_class.sql` และ `add_asset_extensions.sql` ก่อน จากนั้นรัน:

```sh
node scripts/migrate-asset-schedule.mjs
node scripts/migrate-asset-schedule.mjs --apply
```

สคริปต์อ่านการเชื่อมต่อจาก `.env` ตรวจข้อมูลก่อนขยาย CHECK constraints และเพิ่มประเภทย่อยตามเอกสาร รันซ้ำได้ ไม่แก้รายการทรัพย์สินเดิม ไม่ล้างรายละเอียดเดิม และไม่เปิดประเภทย่อยที่ผู้ดูแลปิดใช้งานไปแล้ว

## ตัวกรอง

คำค้นหา ประเภท และสถานะเป็นตัวกรองหลัก เมื่อเลือกประเภทนอก IT จะแสดงประเภทย่อยของประเภทนั้น ตัวกรองอำเภอ หน่วยงาน กลุ่มงาน MA และการเรียงลำดับอยู่ใน “ตัวกรองเพิ่มเติม” การเปลี่ยนประเภทล้างประเภทย่อย/อุปกรณ์เดิมเพื่อป้องกันเงื่อนไขที่ขัดกัน การกรองประเภทย่อยใช้ `subtype` ใน URL และใช้กับการส่งออกได้ด้วย
